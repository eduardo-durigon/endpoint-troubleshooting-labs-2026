## 🧪 Lab 01 – Apple - Storage and Disk Investigation

### 🎯 Objective

Investigate disk usage on a macOS system and determine whether cleanup is required.

---

### 🛠️ What I Did

* Checked system storage using “About This Mac”
* Reviewed storage categories and overall disk usage
* Opened Storage Management to analyze files
* Inspected Downloads folder for unnecessary files
* Reviewed Applications for large or unused programs
* Checked Trash for reclaimable space

---

### 🔐 Key Concepts

* Disk usage analysis
* macOS storage categories
* File and application management
* User-level troubleshooting
* Preventive system checks

---

### 🧪 Results

* System has sufficient free disk space
* No significant large or unnecessary files identified
* Applications and Downloads folder are already well managed
* Trash was empty, no recoverable storage

---

### 🧠 Takeaway

This lab showed me that troubleshooting is not always about fixing a problem, but also about verifying that a system is working correctly. I learned how to check storage usage on macOS and confirm when no action is needed.

---

### 🧠 Reflection

Even though no cleanup was required, this lab helped me practice a real-world IT scenario where a user might report low disk space. Being able to confidently investigate and confirm system status is an important skill.
