# Screenshots

This directory contains screenshots captured during the completion of the **Lab 07 – Network Services and Troubleshooting** project.

The screenshots document the practical tasks performed throughout the lab, including network configuration analysis, DNS resolution testing, HTTP/HTTPS communication, TLS certificate inspection, port connectivity testing, DNS record queries, time synchronization verification, traceroute analysis, active connection monitoring, web response header inspection, DHCP/APIPA verification, and wireless networking information.

Sensitive information such as local IP addresses, MAC addresses, DNS server addresses, device names, and other potentially identifiable details has been redacted where appropriate before publication.

These screenshots serve as supporting evidence for the commands executed, observations made, and conclusions documented in the main project README.
