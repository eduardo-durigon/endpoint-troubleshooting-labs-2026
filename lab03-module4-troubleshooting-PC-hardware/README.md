# Module 4 MacBook Air Troubleshooting Lab

## Objective

The objective of this lab was to practice hardware, storage, boot, performance, battery, display, audio, camera, logging, and backup troubleshooting on a MacBook Air running macOS.

## Related Study Notes

This lab complements my CompTIA A+ Core 1 Module 4 notes, where I studied hardware troubleshooting concepts including storage devices, power issues, startup problems, cooling systems, and display troubleshooting.

## Tasks Performed

### System Information

* Reviewed hardware specifications using About This Mac and System Information.
* Verified model, chip, memory, and operating system information.

### Storage Diagnostics

* Inspected storage configuration using Disk Utility.
* Verified APFS volume information.
* Executed First Aid on the startup volume.

### Boot Troubleshooting

* Accessed Startup Options.
* Reviewed recovery and startup tools.
* Successfully booted into Safe Mode.

### Performance Monitoring

* Monitored CPU usage.
* Reviewed memory utilization and memory pressure.
* Examined energy consumption.
* Checked disk activity.

### Battery and Power

* Reviewed battery status and battery health.
* Verified power settings and Low Power Mode configuration.

### Display Troubleshooting

* Reviewed display scaling and brightness settings.
* Verified True Tone functionality.

### Audio and Camera Testing

* Confirmed audio input/output functionality.
* Tested built-in camera operation.

### System Logs

* Used Console to review system log entries and search for errors.

### Backup and Recovery

* Reviewed Time Machine configuration and backup options.

---

## Results

### Storage Health

Disk Utility First Aid completed successfully.

* File system check exit code: 0
* Operation successful
* No storage errors detected

### Performance

System performance appeared healthy.

* CPU utilization remained low
* Memory Pressure remained green
* No swap memory was being used
* No abnormal disk activity was observed

### Battery Health

Battery health was reported as Normal.

### Display

No display issues were observed during testing.

### Audio and Camera

Both devices functioned normally.

### Backup Status

Time Machine was available but no backup disk was currently configured.
